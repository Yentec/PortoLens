# PortoLens

Personal finance and wealth management SaaS, built as a modular monolith.

## Requirements

- Node.js 26 (see `.nvmrc`)
- npm 11

## Repository layout

```
apps/         deployable applications (API, web)
packages/     shared libraries (primitives, contracts)
docs/adr/     architecture decision records
```

## Getting started

```bash
nvm use
npm install
```
